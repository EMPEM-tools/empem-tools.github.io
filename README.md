# EMPEM Tools

Landing page for the EMPEM-tools browser-based analysis tools.

- **dot.plot** — epitope response visualization → https://empem-tools.github.io/dotplot-tool/
- **Contacts Explorer** — PDB inter-chain contact analysis → https://empem-tools.github.io/contacts-explorer/

All tools run entirely client-side: no uploads, no accounts, no data leaves
the visitor's browser.
